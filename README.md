# Animate with SayMaker (Firefox)

Right-click any image on the web, choose **Animate with SayMaker**, pick a model, and the image opens in [SayMaker](https://saymaker.ai/?utm_source=firefox&utm_medium=extension)'s video generator as the first frame of a new clip. Describe the motion and generate.

Models in the menu: Kling 3.0, Veo 3.1, Seedance 2.0 and MiniMax H3 Fast (the one a free account can run). Veo 3.1, Kling 3.0 and Seedance 2.0 need a plan or a credit pack ([pricing](https://saymaker.ai/pricing?utm_source=firefox&utm_medium=extension)).

The extension only adds the menu and opens a tab. It reads nothing on the page except the address of the image you right-clicked, and collects no data. Images served as `data:` or `blob:` URLs cannot be passed by address; the generator opens empty and you upload the file instead.
